## Overview

Inspire Youth Tutoring is dedicated to helping 3rd through 8th graders excel in their academic pursuits. Our website serves as a hub for parents and students to learn about our services, meet our tutors, read testimonials, and get in touch with us.

## Project Structure


- **public/**: Contains static files such as images, CSS, and JavaScript.
- **src/**: Contains the main source code for the React application.
  - **components/**: Reusable UI components.
  - **pages/**: Different pages of the website.
  - **App.jsx**: Main application component.
- **README.md**: This file.
- **package.json**: Project dependencies and scripts.
- **.gitignore**: Files and directories to be ignored by Git.

## Technologies Used

## Setup and Installation

To set up the project locally, follow these steps:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/inspire-youth-tutoring.git
    ```
2. **Navigate to the Project Directory**
    ```bash
    cd inspire-youth-tutoring
    ```
3. **Install the Dependencies**
   ```bash
   npm install
   ```
4. **Start the Development Server**
   ```bash
   npm start
   ```

The website should now be running on **http://localhost:5173**
